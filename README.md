# ProGym exercise art generator

Original, procedurally generated 3D exercise illustrations (style "A":
realistic studio render, light grey background, lime muscle highlights) for
the ProGym exercise library. One male and one female animated WebP per
exercise plus JPEG thumbnails.

Everything visible is generated by this code from CC0 inputs (see
`LICENSES.md`): the bodies come from the MakeHuman base mesh and its
CC0 shape targets, the equipment is modelled from primitives, clothing is
painted per vertex, lighting and floor are procedural.

## Output per exercise

| file | content |
|---|---|
| `<slug>.webp` | male, 480x320 animated WebP, 12 frames x 167 ms (2 s loop: start -> end -> start with holds), <= 45 KB |
| `<slug>.f.webp` | female, same |
| `<slug>.thumb.jpg` / `<slug>.f.thumb.jpg` | 160x107 JPEG of the end pose |

`slug` is Laravel `Str::slug(name_en)`.

## Requirements

- Python 3.11 venv with `bpy==4.5.*`, `numpy`, `pillow`
  (`python3.11 -m venv venv && venv/bin/pip install "bpy==4.5.*" numpy pillow`).
- CPU rendering only (Cycles, 8 samples + denoiser), about 30 s per exercise
  per gender on one core.

## Steps

```sh
python3 tools/fetch_assets.py                    # CC0 MakeHuman files -> assets/mh (pinned commit)
venv/bin/python -m artgen.body_model             # build male/female bodies (cached in work/cache)

# work list from the ProGym exercise table (CSV export)
venv/bin/python -m artgen.worklist --csv exercises.csv --out data/worklist.csv --review data/review.csv

# render everything in batches (both genders in parallel), with contact sheets and tar.gz packs
ART_PYTHON=venv/bin/python venv/bin/python tools/run_batches.py --csv data/worklist.csv --out out --batch 100
```

The exercise table CSV needs the columns `name_en, muscle, target_muscles,
secondary_targets, equipment, equipment_tags, pattern, force, mechanic`
(extra columns are ignored). An optional `template` column forces a
movement template for a row. Muscle words in English or Persian are mapped to
the 22 highlight keys in `artgen/muscles.py`.

`data/review.csv` lists rows whose movement template is approximate
(`approx`) or only chosen from the muscle group (`fallback`); set the
`template` column for those rows to override.

## Exercise table 3.2.0 (dist/ex3d)

```sh
venv/bin/python -m artgen.worklist --csv data/table-3.2.0.csv --out data/worklist-3.2.0.csv --review data/review-match-3.2.0.csv
# render rows without an existing render (one process, niced), then assemble
ART_PYTHON=venv/bin/python nice -n 10 venv/bin/python tools/run_batches.py --csv data/render-3.2.0.csv --out out3 --batch 50 --serial --threads 2 --pack ""
python3 tools/make_dist.py --work data/worklist-3.2.0.csv --new out3 --old out --dist dist/ex3d --review data/review-3.2.0.csv
```

Keys are `Str::slug(name_en)` (a later duplicate gets `<key>-<id>`). Templates come from the
table rules (`TABLE_RULES`), then the general rules; `equipment_tags` decide the implements and
`pattern` is checked against the template (mismatches are marked `approx`). `dist/ex3d` holds the
four files per row plus `manifest.json` (`{"v":1,"items":{"<id>":"<key>"}}`).

## Layout

- `artgen/body_model.py` - MakeHuman base + targets -> athletic male/female, skeleton, weights
- `artgen/rig.py` - numpy FK / two-bone IK with pole vectors / hand and foot frames / skinning
- `artgen/paint.py` - clothing, shoe and hair regions, 22 soft muscle regions
- `artgen/poses.py` - constraint pipeline (balance over the feet, reach, support contact), arm holds
- `artgen/fam.py` - set-ups: bench, plank, hanging, seated, floor
- `artgen/tpl_*.py` - the movement templates (start/end key poses + per-template details)
- `artgen/equipment.py` - equipment from primitives
- `artgen/scene.py`, `artgen/render.py` - studio scene, camera fit, rendering, WebP encoding
- `artgen/qa.py` - automatic checks (floor penetration, foot sliding, grip offsets, reach)
- `artgen/worklist.py` - work list + template inference + slug
- `tools/` - asset fetch, smoke test, batch runner, release uploader

## v3 engine (dist/ex3d v3)

Smoother, spec-driven animations: 24 frames per 2.4 s loop with eased
timing, short holds at both ends and a slower lowering half where the load is
lowered; unique poses are solved in order with warm starts and rendered once.

| file | content |
|---|---|
| `<key>.webp` / `<key>.f.webp` | 480x320 animated WebP, 24 frames, per-frame durations (about 70-110 ms), <= 90 KB |
| `<key>.thumb.webp` / `<key>.f.thumb.webp` | 480x320 still WebP (q 82) of the most telling pose |

Every image carries a small `© ProGym` mark in a free bottom corner (drawn
from strokes in `artgen/mark.py`, identical in every frame) and copyright
metadata (EXIF Artist / Copyright, XMP dc:rights / dc:creator).

```sh
python3 tools/make_moves.py                          # data/spec/part-*.csv -> data/v3/moves.csv (+ moves-review.csv)
venv/bin/python tools/posecheck.py data/v3/moves.csv # solve every loop + automatic checks, no rendering
venv/bin/python -m artgen.render3 --moves data/v3/moves.csv --gender m --out out_v3 --preview --only KEY  # start/mid/end only
tools/render_all.sh data/v3/render-order.csv out_v3  # both genders in parallel, niced, resumable
venv/bin/python -m artgen.sheet3 out_v3 sheets/v3    # contact sheets with the QA results
python3 tools/make_dist3.py --moves data/v3/moves.csv --renders out_v3 --dist dist/ex3d --pack dist/ex3d-v3.tar.gz
```

manifest.json: `{"v":2,"names":{"<name_en>":"<key>"},"thumb":"webp","size":[480,320]}`.

Review and release gates:

- `data/v3/qa-accepted.csv` (key, gender, issue, reason) - automatic-check findings reviewed by eye and accepted
  (e.g. the Zottman / Arnold wrist rotation). Any other open finding blocks `make_dist3.py`.
- `data/v3/excluded.csv` (name_en, reason) - rows whose drawing does not yet match the exercise's own steps.
  They are left out of the files and the manifest (no picture rather than a wrong one).
  `data/v3/excluded-notes.txt` keeps the same list by key.
- `python3 tools/review3.py issues out_v3` lists open findings; `tools/stale3.py ... --requa` refreshes the
  findings of renders whose poses are unchanged and lists the renders that are out of date.

Layers added in v3:

- `artgen/motion.py` - loop timelines (rep, alt, hold, cycle, flight) and easing
- `artgen/spec3.py` - move rows (data) -> template parameters (`P(row, key)`), tempo, camera, thumbnail pose
- `artgen/tpl_v3.py` - archetypes driven by those parameters (bench angle, grip, attachments, olympic lifts, ...)
- `artgen/kit.py` - cables with rope / bar / lat bar / V / D handles / ankle cuff, bands with anchors, machine levers, bench racks
- `artgen/overlay.py` - implements named by the spec but not drawn by an archetype (straps, bands, mini bands, cables, Smith, single bell)
- `artgen/mirror.py` - left/right mirror of a solved pose (alternating reps)
- `artgen/qa3.py` - contact (grip, feet, supports, floor), motion (pops, twists) and range checks
- `artgen/render3.py`, `artgen/sheet3.py`, `artgen/mark.py` - renderer, contact sheets, copyright mark
